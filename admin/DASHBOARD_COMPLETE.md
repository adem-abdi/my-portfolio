1. Go to: `http://localhost/your-portfolio/admin/`
2. Login: `adem` / `admin123`
3. Enjoy the new professional interface!

### **Managing Content:**

#### **📊 Dashboard Overview**
- **View Statistics**: Live counts of all content
- **Quick Actions**: Click buttons for fast navigation
- **Monitor Status**: Check portfolio and system health

#### **🏠 Hero Section**
- Click "Hero Section" in sidebar
- Edit your main presentation content
- Upload new profile image
- Update statistics and CTA buttons
- Click "Update Hero Section"

#### **🛠️ Services**
- Navigate to "Services" section
- **Add Service**: Click "Add New Service" button
- **Edit Service**: Modify title, description, highlighting
- **Remove Service**: Click "Remove Service" with confirmation
- Click "Update Services" to save all changes

#### **💼 Projects**
- Go to "Projects" section
- **Add Project**: Click "Add New Project" button
- **Edit Details**: Title, description, dates, links, tech stack
- **Upload Images**: Project screenshots with preview
- **Set Featured**: Mark important projects as featured
- **Remove Project**: Delete with confirmation
- Click "Update Projects" to save

#### **🎯 Skills**
- Navigate to "Skills" section
- **Add Skill**: Click "Add New Skill" button
- **Set Proficiency**: Use percentage (0-100%)
- **Choose Category**: Frontend, Backend, Database, Tools, Other
- **Remove Skill**: Delete with confirmation
- Click "Update Skills" to save

#### **💬 Testimonials**
- Go to "Testimonials" section
- **Add Testimonial**: Click "Add New Testimonial" button
- **Client Info**: Name, title/company
- **Testimonial**: Client feedback text
- **Rating**: 1-5 star rating system
- **Remove**: Delete with confirmation
- Click "Update Testimonials" to save

#### **📞 Contact Info**
- Navigate to "Contact Info" section
- **Update Details**: Email, phone, address
- **Social Media**: Add/update social media URLs
- **Validation**: Real-time URL and email checking
- Click "Update Contact Information"
